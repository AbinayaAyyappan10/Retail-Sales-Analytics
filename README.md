# Retail Sales Analytics Using Python

## Project Overview
Analyzed retail sales data to understand sales performance, customer purchasing behaviour and business trends.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Jupyter Notebook
- Power BI

## Key Analysis
- Data Cleaning and Preparation
- Exploratory Data Analysis (EDA)
- Order Status Analysis
- Correlation Analysis
- Outlier Detection using IQR
- Customer Segmentation using RFM

## Objective
To transform retail data into meaningful insights and support better business decisions.
